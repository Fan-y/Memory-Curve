# Memory Curve 产品演进计划（2026 下半年）

## 产品定位
- 一句话定位：帮助用户把“知识记录”转化为“长期记忆”。
- 核心价值：减少遗忘、建立复习节奏、让学习可持续。
- 目标用户：备考人群、知识工作者、长期学习者。

## 北极星指标与关键指标
- 北极星指标：连续 2 周每周完成至少 3 次复习的活跃用户数。
- 激活指标：新用户 24 小时内完成“创建首条内容 + 完成首次复习”的比例。
- 留存指标：D1、D7、D30 留存。
- 质量指标：每周人均完成复习次数、逾期任务占比、用户主动回访率。

## 演进原则
1. 先保证学习闭环，再追求功能丰富。
2. 每个阶段只解决一个核心用户问题。
3. 以指标变化和用户反馈决定下一阶段投入。
4. 保持小步快跑，避免一次性大范围改版。

## 下一阶段路线图（产品视角）

### 阶段 7：新手激活优化（P0）
要解决的问题：新用户首次使用门槛高，首日流失明显。

计划动作：
1. 增加首登引导与空状态教学。
2. 增加“3 分钟完成首次复习”新手任务流。
3. 在关键节点提供轻提示，减少操作犹豫。

验收口径：
1. 新用户 24 小时激活率提升到 55% 以上。
2. 新用户首次复习完成时长中位数下降 30%。

### 阶段 8：习惯养成（P0）
要解决的问题：用户知道该复习，但没有形成稳定节奏。

计划动作：
1. 增加周目标设置与达成反馈。
2. 增加复习提醒策略（不过度打扰，可调频率）。
3. 增加连续学习天数与阶段成就反馈。

验收口径：
1. D7 留存提升到 35% 以上。
2. 每周至少 3 次复习用户占比提升到 40% 以上。

### 阶段 9：学习效率提升（P1）
要解决的问题：用户投入时间后，难感知学习收益。

计划动作：
1. 增加“易遗忘内容优先复习”推荐视图。
2. 增加按主题回顾与阶段性复盘报告。
3. 增加更可解释的学习进展反馈。

验收口径：
1. 逾期任务占比较当前下降 20%。
2. 周回访率提升 15%。

### 阶段 10：增长与传播（P1）
要解决的问题：产品价值明确，但自然增长慢。

计划动作：
1. 增加学习成果分享卡片。
2. 增加可复用学习模板与示例内容。
3. 设计轻量邀请与回流机制。

验收口径：
1. 邀请带来的新增用户占比达到 10%。
2. 被邀请用户 D7 留存不低于自然新增用户。

## 里程碑定义
- M1（已达成）：用户能完成从创建到复习的最小闭环。
- M2（已达成）：用户能完成完整 MVP 学习旅程。
- M3（进行中）：把激活与留存做成可持续增长曲线。
- M4（规划中）：建立分享传播与自增长能力。

## 风险与应对
1. 风险：功能变多但用户不活跃。
    应对：以激活率和留存为优先级，低价值功能延后。
2. 风险：提醒策略引起打扰，导致关闭通知或流失。
    应对：默认温和提醒，提供频率与时段设置。
3. 风险：用户输入成本高，导致早期放弃。
    应对：强化模板、示例和最小输入路径。

## 复盘机制
1. 每两周做一次阶段复盘：看指标变化、看用户反馈、看流失节点。
2. 每月更新一次路线图：保留有效动作，淘汰低收益事项。
3. 所有新需求先回答两个问题：是否提升激活，是否提升留存。
